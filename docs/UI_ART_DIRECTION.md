# LCT 界面美术方向

## 资料范围与证据边界

本界面是莱茵生命主题的原创转译，不是官方网站、游戏界面的逐像素复刻或官方授权产品。没有打包官方标志、角色立绘或活动截图；LCT 字标、条形标记、进度仪表均为项目原创。

## 主方向

**科学机构的信息秩序，服务于逐句准确表达。**

采用机构出版与操作型工作站，而非活动大厅复刻。冷白文档是阅读场，深绿侧栏是组织导视，淡绿承载状态与译文；暖色仅标识待处理事项和细小出版色标。色值是本项目设计决定，不宣称属于官方 token。

《孤星》只提供机构排版、窄色条和向外探索的辅助语汇；不把整个工具做成星空。原创轨迹仪表只出现在总览，并绑定真实翻译完成率，其他页面的主角是文字。没有临摹官方阵营图形。

- 总览：首先识别当前项目、翻译完成率和待译工作，下一步进入工作台或待译队列。
- 工作台：原文与译文左右对照，窄屏上下排列；路径、说话人、阶段与上下文服从正文。
- 检索：项目词条和 TM 两个来源并列，不将记忆匹配冒充审核结果。
- 审校：一次只呈现一个待译条目，成功保存并通过接口返回的 QA 后自动推进；失败留在当前条目并解释原因。

## 交互与技术边界

保留 React、Vite、Lucide 和既有 Rust API；旧页面 JSX、内联样式、深色变量与仿阵营标志均不保留。CSS Grid、原生 SVG 和 CSS 分层短动效完成构图，不增加 3D 或大型动效依赖。响应式断点覆盖侧栏压缩、移动端顶部导航与双语栏重排；`prefers-reduced-motion` 禁用运动，顶栏“减少动态效果”开关可在本次会话内进一步关闭动画，不能反向覆盖系统偏好。

Zod 仅验证外部 API 响应；Prettier 负责本次新组件与样式格式一致性。字体使用本地字体栈，不依赖在线字体服务。Vite 开发与预览代理指向本机 3000 端口；生产界面由原有 Rust 静态服务提供。

项目统计来自接口，不再设置假初始数量或固定“100% QA 通过”。保存接口使用数据库原文校验，在 QA 失败时拒绝写入；要求项目标识和读取时的版本，后端执行锁定与并发冲突检查。页面保存后刷新关联查询，旧版本草稿保留并阻止覆盖新记录。完整生产门槛见 `PRODUCTION_TODO.md`，单条 QA 不等同于译文语义验收。

## 验收入口

在仓库根目录运行 `pnpm --dir ui build` 后，使用 `cargo run -p loc-cli -- ui --port 3000 --no-open` 打开本地服务。开发模式另运行 `pnpm --dir ui dev --host 127.0.0.1`。

- `pnpm --dir ui format:check`：格式检查。
- `pnpm --dir ui test:smoke http://127.0.0.1:3000`：真实接口契约、分页、阶段筛选、搜索、空结果与非持久化格式修复；需要支持直接运行 TypeScript 的 Node 22.18+。
- `cargo test --workspace`：仓库现有测试。

写入与键盘保存验收在 `.loc/ui-review/project.db` 的 SQLite backup 副本上运行，真实主数据库不作为测试写入目标。视觉认可仍以用户对莱茵生命气质、信息密度和阅读体验的判断为准，构建通过不代表美术验收通过。

## 动效与视觉验收

动作语汇是“展开、落位、描线、确认”，延续机构出版与研究仪表，而不是仿造游戏过场。`ui/src/motion.css` 统一管理节拍与缓动，不新增依赖：

- 结构色条先展开，标题在 480ms 内短距离落位；统计项以 45ms 间隔出现，数值始终是真实值，不做伪计数。
- 仪表轨迹最多 900ms 完成一次描线，辅助线最终保持 0.17 透明度；没有循环装饰。转场不等待动画结束，不重建工作台或清空草稿。
- 导航标记短展开，动作箭头轻微位移；编辑区聚焦时加强边界和译文底色，按钮处理态显示真实忙碌图标，成功提示局部显现。
- 正文不做滚动视差或逐卡片揭示；长列表保持稳定，只有真实请求的加载图标循环。
- 提高桌面辅助文字可读性；审计页用分组线、内容内边距、可读路径字号和可键盘操作的详情建立层级。

已通过内置浏览器而非外部插件，观察总览、工作台、检索、审计和待审队列。隔离数据库副本位于 `.loc/acceptance/motion-hzs80j_w/data`，截图为同目录上一级的 `overview.png`。实测草稿跨页保留、快捷保存后按钮禁用、队列推进与下一条焦点、审计详情展开，以及键盘切换减少动态效果。读取浏览器计算样式确认入场起点／终点、辅助线透明度和静态模式 `animation: none`；浏览器控制台未捕获应用错误。

390×844 视口下，总览、检索、审计没有横向溢出，待审编辑区上下重排并保持焦点可见；验收后恢复默认视口。系统级 reduced-motion 媒体偏好未做模拟切换，仅检查对应 CSS 并实测应用内开关；不将其写成已实测。最终视觉偏好仍需使用者签收。


## 仪器化增强（第二轮）

在“机构出版与操作型工作站”方向不变的前提下，本轮把界面从静态文档推进为正在运转的观测仪器；灵感仍来自莱茵生命的观察窗、培养刻度与《孤星》的校准环语汇，不引入暗场、圆环 HUD 全覆盖或通用科幻装饰。所有新增运动绑定真实状态，不做伪计数，无信息量的循环装饰仍被禁止。

- 总览仪表新增 72 刻度环（每 6 格主刻度）与 25/50/75/100 百分比标尺，刻度与数值同源于真实完成率；校准弧沿虚线环扫掠一周后停在顶部，信标在轨迹描线完成后只做一次 ping 扩散。
- 仪表底板加入低对比蓝图网格（4–6% 透明度结构色），仅作用于仪表区，不进入正文与编辑区。
- 编辑器四角加入观察窗括号，聚焦时括号扩张点亮并叠加既有边界/底色反馈；阶段徽章前置同色状态点，锁定时仍显示锁图标。
- 待审队列新增批次进度细轨（role=progressbar，含 aria 值），宽度随当前条位置过渡；筛选器选中态获得左侧金色内嵌标记与背景扫掠。
- 页面级加载改为双弧校准环（仅真实请求期间旋转）；连接状态点在 pending 时脉搏、连接后静止；统计行数值落位后描出绿金基线尺；品牌条形与章节标题刻度在入场时落位。
- 顶栏连接状态改为等宽字体读数；其余字体栈、字号底线（11px）与响应式断点不变。

验证：真实 449MB 项目库（144,181 条）下截取总览、工作台、检索、审计、待审的 1600×900、1280×800、800×900、390×844 渲染；确认刻度环、蓝图网格、括号、批次轨与筛选标记的静态终点，以及 reduced-motion 下仪表完整静态呈现（ping 隐藏、扫掠弧停于顶部）。编辑器聚焦态括号扩张与琥珀色焦点环实测生效。`pnpm format:check`、`test:smoke`、`test:editor` 与 `cargo test --workspace`（33 个套件）全部通过。截图与 playwright-core 无头工具位于 `.loc/tools/`，仅作设计验证，不进入运行时依赖。

## 观测舱氛围与陀螺仪（第三轮）

应用户明确要求，在不动阅读区的前提下为总览观测舱加入环境动效与空间交互；全部仍以真实状态为驱动（陀螺仪跟随真实指针位置），且遵守双开关 reduced-motion 约定。

- 观测舱氛围层 `.hero-ambience`：约 13 秒一周期的垂直扫描光带（《孤星》观测扫描语汇）、14 枚培养悬浮微粒（实心点/空心培养环/暖金分析点三种形态，各自独立的上升周期 18–33s、摇摆周期与负延迟预分布）、仪表底板蓝图网格 46s 无缝漂移一格（28px 周期）。静态终态全部不可见或保持原样，reduced-motion 下自然消失，无需额外隐藏规则。
- 陀螺仪仪表（眼球式常平架结构，第三轮迭代）：跟踪范围从 hero 区扩至整个窗口——光标在任何位置仪表都保持朝向，仅离开窗口或 reduced 时回平。倾角加大（框架 ±18°/±14°，perspective 900px）。SVG 四层——眼眶框架（十字准线/刻度环/标尺，快通道强跟随并朝指针方位平移）、校准环（虚线环 36s 进动 + 扫掠弧，中通道）、轨道平面（轨迹椭圆/信标/ping 组成进动组 64s/周，信标如卫星沿轨道绕行）、内环常平架（进度轨道 + 真实进度弧，最强反向抵抗，translateZ 40px），中心读数为“瞳孔”（translateZ 72px 悬浮）。刻度环本身 120s/周慢转，角部十字标 4.8s 交替呼吸闪烁。三通道惯性插值（0.16/0.095/0.055）让各层先后到位，读作装配中的仪器而非刚体；指针离开窗口或 reduced 时归零回平，静止后 rAF 自动休眠，仅精准指针设备启用。
- 验证：三通道变量待机未设置、指针移动后按快→慢收敛（fast 0.85 / slow 0.82 同时刻差异可见）、reduced 切换后全部归零且进动停止；两个对角方向的倾斜态截图确认各层方向性分离。倾斜态下阅读区与其余页面元素保持静止。

## 字体与文字栅格化

实测原顶栏为 12px、默认行高，没有容器裁切，但小字号使汉字笔画辨认困难；响应式样式曾将注记缩至 6–9px。现将最小声明字号提高为 11px、顶栏改为 14px/24px，并明确基础 1.6 行高，窄屏顶栏允许分行而不挤压文字。保留本地中文字体栈，字体匹配检查可找到 Noto Sans CJK SC，不新增字体下载，也不宣称计算样式能证明每个字形实际选用的字体。

移除强制文字平滑覆盖，使用浏览器默认栅格化；文字入场动画仅保留起始填充，结束后释放 transform，仪表文字改为布局居中而非小数像素 translate。内置浏览器实测标题与仪表结束态均为 `transform: none`，390 像素视口无横向溢出。顶栏前后原始像素截图在 `.loc/acceptance/font-rendering/header-before.png` 与 `header-after.png`；最终屏幕观感仍受显示缩放与设备影响，不将字号修复宣称为所有操作系统的字体渲染认证。

## 缩放与响应式对齐

仪表 SVG 与完成率文字共用同一 Grid 单元格，内边距统一由仪表容器承担；不使用断点百分比 top 或文字 translate 补偿。窄屏图形最大宽度受容器约束，导航以最小 120px 的网格项自动换行，避免缩放触发窄屏后标签互相挤压。

内置浏览器覆盖 320、390、768、960、1280、1553、1599、1600、1616、1920、2242px 的视口宽度：图形与文字块中心差均小于 0.01 CSS px，页面无横向溢出，导航项无内部横向裁切；文字保持 `transform: none`。测量结果位于 `.loc/acceptance/zoom-layout/measurements.json`。这是响应式重排验证：内置浏览器的 Ctrl+- 未改变实际 CSS 视口，因此不将其冒称为浏览器原生缩放倍率验收。
