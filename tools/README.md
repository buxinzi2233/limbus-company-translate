# 历史语料维护与源资源审计工具

这里完整保留本项目既有工作区中的 15 个 Python/依赖文件（不包含缓存），逐文件哈希见 [manifest.json](manifest.json)。普通翻译用户**不需要运行这些脚本**：新工作区使用发布包中的已验证参考快照，入口见[主 README](../README.md)。

| 目录 | 用途与边界 |
| --- | --- |
| `wiki_reference/` | 导入已采集的公开 Wiki 响应、署名及版本，建立独立参考库并只读检索；不是 LCT 的 AI MCP 服务 |
| `corpus/` | 从显式来源构建中文字段索引；`build_names.py` 是固定历史名称对照，不是通用名称生成器 |
| `source_audit/` | 对用户自行提供的游戏资源、历史目录及快照执行边界调查；不附带原始游戏资源 |

脚本来自历史调查工具链，输入布局和版本具有特定前提，不能替代现行 LCT 的导入、范围门禁或审校流程。部分脚本使用 Python 3.12+ 类型别名语法；资源解析依赖在 `source_audit/requirements.txt`，需要时在独立虚拟环境安装，不要全局安装。不运行历史工具即可完整使用预编译包；这些工具不承诺一键重新采集网络资料或自动重建未分发的游戏快照。

本次仅验证文件完整性与 Python 语法；没有用私人游戏资源重新执行整套历史调查。各可执行脚本的参数以其 `--help` 和模块说明为准，辅助模块无需直接执行。不要将历史源码内的版本常量、示例路径或判断规则当作当前生产事实。
